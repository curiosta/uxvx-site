Curiosta · proof of concept

See where reading gets hard.

UXVX watches (only if you say yes) where your eyes linger on a page, flags paragraphs you dwell on or re-read, and can explain them more simply — with your own LLM key or a local mock. Video stays in the browser.

Try the live demo Extension (private beta)

How the demo works

No install. One sample article. Honest limits on webcam accuracy.

  • 1 · Consent

    Camera off until you opt in

    Nothing starts until you tick the consent box and press Start. Stop anytime. Frames are processed in memory only.

  • 2 · Gaze

    Rough paragraph-level tracking

    WebGazer estimates where you’re looking. It’s coarse (±100–200 px) — enough for a paragraph, not a word. Calibrate in good light.

  • 3 · Explain

    Your key, or a mock

    Flagged text can go to xAI / an OpenAI-compatible API you configure, or stay local with a mock explanation. Keys live in localStorage only.

Reading now, UX insight later

Same on-device stack can later score how people attend to a layout — still without shipping video off the device.

What’s real today

This site is a self-contained reading PoC. The Chrome extension at curiosta/uxvx is the same idea for any page you already browse — currently a private beta, not a public Web Store listing.

What’s not claimed

Webcam gaze is not clinical eye-tracking. Struggle thresholds are heuristics. Facial “emotion” reading is not in this PoC. We don’t sell biometric data.

Extension on GitHub (private beta) Use the site demo instead

Developers with repo access: clone, open chrome://extensions, enable Developer mode, Load unpacked, pick the folder. See the extension README for providers (xAI, OpenAI-compatible, Ollama).

Privacy in one screen

  • Camera off by default; opt-in only.
  • No video, images, or face landmarks leave the device.
  • API keys stay in your browser storage.
  • Only paragraph text you ask to explain is sent to the LLM you choose.
  • No analytics backend on this PoC.
